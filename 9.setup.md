# Setup

## Requirements

- Git (optional, for source control)
- Python 3 for the simplest local static server, or another static HTTP server
- No Node.js, package manager, database, cloud account, or environment file required

## Run locally

From the project root:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000` in a browser. Press `Ctrl+C` in the terminal to stop the server.

You can also open `index.html` directly, but an HTTP server more closely matches deployment and avoids browser-specific file URL restrictions.

## Publish

Upload the repository contents to a static hosting service or configure a web server to serve this directory. Set `index.html` as the default document. Enforce HTTPS at the hosting layer and ensure the `assets/` directory is included.

The site has no build output directory and no secrets/configuration to provision. Do not add API keys to the static deployment environment; values delivered to browser code are public.

## Resume asset

If adding a downloadable resume, place a reviewed public-safe PDF under `assets/` (for example `assets/resume.pdf`), confirm that it loads from the deployed site, and add an accessible link. Do not commit a resume containing private address/phone details unless intended for public distribution.
