# Contributor and AI Agent Guide

## Project context

This repository is a lightweight static DevOps resume portfolio. Keep the implementation dependency-free unless a specific, documented requirement justifies a dependency. The project roadmap is aspirational until a working project and public evidence exist.

## Before editing

1. Read `README.md` and the relevant numbered specifications.
2. Inspect existing content and working-tree changes before modifying files.
3. Confirm claims, links, and project status against owner-provided evidence; do not invent employment, metrics, certifications, deployments, or project completion.
4. Keep unrelated legacy assets untouched unless they are explicitly in scope.

## Implementation guidance

- Use semantic HTML, responsive CSS, and small vanilla JavaScript enhancements.
- Preserve keyboard access, focus visibility, readable contrast, and reduced-motion support.
- Keep portfolio text and navigation useful without JavaScript.
- Use relative local asset paths.
- Never add secrets, private personal data, tracking, or unapproved integrations.
- External links opened in another tab must use `rel="noopener noreferrer"`.
- Do not add authentication, a database, API, analytics, or MCP to the static site without an approved requirement and updated security/architecture docs.

## Project case-study standard

Mark work as Planned, In Progress, or Complete accurately. Before a project can be listed as Complete, verify its repository exists and document its purpose, architecture, individual contribution, tools actually used, setup, tests, security considerations, and working demo or evidence where available.

## Verification

Run the checks in [14.testing-and-qa.md](./14.testing-and-qa.md). Fix regressions caused by the change; do not hide failures or weaken checks to pass. Report what was tested and what remains unverified.
