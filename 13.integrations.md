## Removed integration

The prior Web3Forms contact integration was removed along with its client-side access key. The current contact section links to LinkedIn and GitHub and does not promise email delivery.

The previous key should be revoked/rotated with Web3Forms. A replacement form integration must use an approved service, understand its data processing and spam controls, and avoid exposing credentials. For a provider requiring a private secret, use a server-side endpoint rather than browser JavaScript.

## Adding an integration

Before integrating a service:

- Confirm owner approval, purpose, and current destination.
- Prefer a normal link over a script, tracker, or API call when it meets the need.
- Review privacy, accessibility, availability, credential exposure, and CSP implications.
- Keep secrets out of public source and browser requests.
- Document failure behavior and validate with network inspection after deployment.
